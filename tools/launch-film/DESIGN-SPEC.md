# AIGC Studio — 把想法，留在画面里

## 制作基准
2026-11-25。用户已选择自主创作，并明确排除 tools/promo 的废弃稿。本工程独立创建；不复用旧片的代码、音频、视频、截图采集或创意结构。不把废弃稿作为比较对象。Bilibili 链接仅保留 UI 动作因果、关键词与音乐配合的抽象启发；不使用对方片源、品牌、配色或音乐，不声称逐帧复刻。

## 产品简报
面向个人创作者、设计师和游戏资产制作者，展示 AIGC Studio 作为本地桌面创作工作台，从想法到生成、加工、归档的一条连续工作流。主张：界面和资产留在本地，推理使用可切换的云端算力。真实功能依据 README、shared/contract.js、真实 web/studio 组件及 preview fixtures。

## 视觉方向
比较了“深色机能”“纯字卡快切”“黑白创作工作室”三方向。选第三种：产品原生的印相室语言，单张相纸开始、真实工作台展开、作品与加工结果成为主角，最后汇聚品牌。避免紫色霓虹、饱和渐变、装饰 HUD、无意义震屏及粒子。相比参考片减小文字闪切密度，让交互和结果读得完。

品牌 tokens：纸白 #f5f5f6，面 #ffffff，墨 #141416，次墨 #52525a，分隔 #dedee3；深场 #141416；状态绿仅用于真实 ready 指示。字体 Segoe UI / Microsoft YaHei，主标题 72–112px，叙事字高 ≥60px，辅助 ≥36px。画面安全边距 84px。圆角 18/24px，作品纸边 3px。3D 只用于建立空间的相纸与工作台；参数和提案段正视。

动效：专业精致、中等能量，常规入场 24–36f，bezier(0.22,1,0.36,1)，无大弹跳；相纸落位只给 ≤1.02 过冲。镜头均匀性由节拍管理，幅度不逐拍脉冲。全片没有震屏。每镜末留静止，品牌落定 ≥1s。原创镜头均逐帧验收，未声称复刻 Gallery 成片。

审美准则 Q8 的有意识取舍：保留各代表作品从四方归位的“合影”结构，采用克制的黑色舞台和长停留；不加入 crane、舞台粒子或强冲击峰值，以保持产品创作工作室的中等能量和印相室材质。

## 参考手法的取舍
|手法|参考启发|本片决定|
|超大关键词|把利益点变成画面中心|采用大字但减少快速闪词|
|紫色空间/辉光|科技氛围|弃用；保持产品黑白灰|
|UI 点击与结果|因果清晰|采用真实截图状态切换、局部运镜|
|强节奏|镜头边界配音乐|按新曲实测节拍剪辑，不拷贝原片声音|
|大量功能蒙太奇|短时间容纳信息|拆成十段，按三类人群串起各自任务|

## 音乐分析记录
`src/music.json` 按当前十段时间线定义章节位置。`scripts/verify-audio.py` 测量 SFX 文件与 BGM 文件在两版成片中的位置和差轨；`analysis/cut-attack-evidence.json` 仍记录旧版分析，不能用于声明当前剪辑点命中实际鼓点。交付前需要对当前成片试听确认乐句与切点关系；波形相关不代表主观听感。

## 复审修正
- 全片在 `Main.tsx` 隐藏场景自带字幕，只保留字幕轨；字幕按文本估算宽度缩字号，进入和离开镜头各淡入 / 淡出。
- 模型卡翻面由 9 帧改成 27 帧，背面有明确停留，再翻回正面。
- 结尾先让输入框退场，再显示正式图标和字标；避免两套标志叠影。
- 透明底素材的 alpha 经 Pillow 确认：背景 alpha 0、主体 alpha 255，RGB 与原图一致。对比分屏把原图放右、抠图放左，并在中段暂停；后段单独放大透明 PNG 到棋盘格背景。
