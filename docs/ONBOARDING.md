# 安装后的初始引导

引导按「了解能力 → 接通一条出图路径 → 可选连接文字助手 → 开始创作」组织。重点是让用户先完成一次可理解的选择，再逐步补充配置。

## 业务依据

| LLM 使用位置 | 实际行为 | 引导演示 |
| --- | --- | --- |
| `server/enhance.js` 的 translate | 保留原意，将描述转写为英文；失败返回原文并标记原因 | 中文描述 → 翻译动作 → 英文提示词 |
| `server/enhance.js` 的 refine / merge | 按模型规则改写英文主稿，给出动态微调方向，合并多个选项 | 草稿 → 英文主稿 → 自动演示选中光影/构图方向 → 合并后的英文主稿，与上方原始描述对照 |
| `server/intent.js` | 解析自然语言需求、多轮上下文、比例、澄清与模型建议 | 融入 Agent 方案演示 |
| `server/routes/agent.js` 与 `server/agent/prompt.js` | 根据模型目录、算力、参考图和舞台上下文形成方案或调用工具；默认新建生图先确认方案 | 需求 → 模型/参数方案 → 用户点击「按此生成」→ 出图通道 → 本机画廊 |

LLM 负责语言理解与工具编排，图像由 GPU 或生图 API 生成。演示不调用 API，也不启动 GPU 任务。图片复用应用原有的毛绒小熊猫示例，并明确标记为内置作品。

翻译与润色演示按预设顺序播放；润色中的四个方向和勾选状态用于说明操作，不是可点击的真实模型建议。实际润色会按题材生成动态建议，用户可以多选后合并。Agent 演示需要用户点击「按此生成」才继续展示内置作品，不提交真实生成任务。未配置 LLM 时仍可使用参数面板和 Agent 的本地草稿；真实翻译、润色需要可用的文字模型，未配置或调用失败会保留原文并标记原因。

## 降低初始配置负担

- 算力页只要求选择一条路径。Kaggle 与 Colab 只露出账号授权和简短默认值说明。
- Kaggle 使用浏览器直连授权，提示手机号验证，保存默认 2×T4；Colab 先用 T4。实际额度以账号与平台为准。
- 保存路径不会启动 GPU 实例。首次生成再准备会话，避免引导期间消耗算力。
- 本机路径复用自动检测和环境准备，不要求新人先填写程序与模型路径。
- 已有生图 API 的用户展开独立入口，只配置一家服务商。内置服务商以 API Key 为核心字段，接口地址可按需展开；自定义服务商还需要接口地址与模型 ID。
- 文字助手是可选步骤；HF Token、高级参数、更多模型和其它后端留到需要时。
- 整体引导和每个配置阶段都可跳过。重新打开入口位于「设置 → 外观与通用」。

## 初次启动与持久化

全局配置记录 `onboarding: { version: 1, status: pending | completed | skipped }`。新配置目录默认 pending；已有配置文件没有此字段时按 skipped 处理，避免升级时打断老用户。完成和跳过通过 `/api/app-settings` 保存，切换工作区不会重复触发。

算力来源与默认 GPU 参数通过 `/api/settings` 保存；文字模型和生图 API 凭据通过 `/api/app-settings` 保存。本机自动准备复用 `/api/local-gpu/setup` 的状态查询与启动/取消操作。保存配置不等于验证服务可用，最终以真实授权、设备检测和生成调用为准。

引导使用独立 PC 页面，保留窗口按钮并继承应用语言与主题。展示动画可暂停和重播；页面隐藏或演示离开可视区域时暂停，恢复可见后继续。系统减少动态效果时默认直接显示文字结果，Agent 仍等待确认。

## 界面范围

引导沿用工作台的灰阶颜色、系统字体、线稿图标与明暗主题，只在本页使用更大的标题、圆形选中标记、开放的提示词流程和错位的示例相纸。入口页标题为 38–58px，其余步骤为 34–46px；小 PC 窗口保留底部操作，正文可滚动。共享设计令牌与 `docs/DESIGN.md` 保持原样，手机不是本次验收目标。

## 本地预览

运行 `npm run preview`，打开 `/__preview?scenario=onboarding-welcome&clean=1`。算力、助手与结束页对应 `onboarding-compute`、`onboarding-connect`、`onboarding-complete`。预览使用离线响应；真实授权与保存走桌面应用本机服务。

完整润色、Agent 等待确认和确认后示例对应 `onboarding-polish`、`onboarding-agent`、`onboarding-agent-confirmed`；英文与深色入口对应 `onboarding-welcome-en`、`onboarding-welcome-dark`。截图等待演示停止后再判定；预览的确认后场景会自动点击示例确认按钮，桌面应用中的用户仍需自行确认。
