# UI 设计规范与系统设计令牌 (DESIGN)

**Creative North Star: "The Monochrome Print Room"**

Imagen Studio 是一间黑白灰的数字印相室：画面始终处于最核心的聚焦位置，控制面板收敛在边缘的灰阶卡片中。全界面摒弃杂乱渐变与彩色光晕，纯粹通过明度层次、发丝细线与克制的触感构建高品质专业生图体验。

---

## Overview

- **设计主旨**：黑白灰为底，墨黑为唯一强调色。图片资产是视觉的核心与主角，界面元素整体退后，形成沉浸、克制、安静的创作环境。
- **色彩策略**：以墨黑（`#141416`）作为主按钮、选中态与激活状态的唯一强调；语义色仅以小圆点或窄提示条形式存在，绝不侵占主界面。
- **排版原则**：严格基于操作系统 UI 原生字体栈，排布清晰的 6 级字阶体系，数字一律启用等宽对齐。

---

## Colors

### 1. 强调色体系 (Primary & Neutrals)
- **Studio Ink (`#141416`)**：系统主强调色。应用于主生成按钮、选中边框、激活图标与关键状态。深色模式下反相为近白 `#f2f2f4`。
- **Ink Lift (`#2b2b30`)**：用于主操作按钮渐变上限。
- **Ink Wash (`#f0f0f2`)**：轻量选中背景（Tab 选中、Chip 激活），深色模式对应 14% 白色透明底。
- **Print White (`#ffffff`)**：卡片、主面板与弹出层的主背景色。
- **Frosted Shell (`rgb(255 255 255 / 86%)`)**：外层毛玻璃大卡，搭配 24px 背景模糊与 140% 饱和度。
- **Sunken Well (`#f4f4f6`)**：下凹表面底色，用于输入框、分段轨道、缩略图背景。
- **发丝描边 (Borders)**：统一使用 1px 细线：
  - `Hairline` (`rgb(18 18 22 / 7%)`)：面板内部内容分隔线。
  - `Panel Edge` (`rgb(18 18 22 / 9%)`)：面板与卡片外轮廓。
  - `Shell Edge` (`rgb(18 18 22 / 8%)`)：外壳与玻璃按钮轮廓。

### 2. 状态指示色 (Signal Colors)
语义色仅以 7px 圆点或窄幅提示条形式出现，禁止大面积填充或用作主按钮底色：
- **在线/就绪**：`#2f8a5c`（浅底 `#eaf5ef`）。
- **排队/预热**：`#a96a18`（浅底 `#f7f0e4`）。
- **失败/异常**：`#c04444`（浅底 `#f9ecec`）。
- **离线/已关闭**：`#a0a0a8`（浅底 `#f1f1f3`）。

### 3. 光桌与相纸 (Stage Materials)
界面只有一处允许出现「实物感」：舞台。它是一张下凹的光桌，上面放相纸。这两组变量定义在 `web/styles/tokens.css` 的浅色 `.ofs-root` 与深色块（`@media (prefers-color-scheme: dark)` / `[data-theme="dark"]`）中，两处必须同步。

| 变量 | 浅色 | 深色 | 用途 |
| :--- | :--- | :--- | :--- |
| `--ofs-mat` | `#f0f0f2` | `#1e1e22` | 光桌表面（比外层玻璃大卡更沉一档，形成下凹） |
| `--ofs-mat-lit` | `rgb(255 255 255 / 92%)` | `rgb(255 255 255 / 7%)` | 光桌顶部柔光（径向渐变，模拟台面透光） |
| `--ofs-mat-inner` | `inset 0 1px 3px rgb(16 16 20 / 6%)` | `inset 0 1px 3px rgb(0 0 0 / 36%)` | 光桌内阴影，说明它是凹进去的台面 |
| `--ofs-print-paper` | `#ffffff` | `#2b2b31` | 相纸，是所在主题里最亮的表面 |
| `--ofs-print-edge` | `rgb(18 18 22 / 10%)` | `rgb(255 255 255 / 13%)` | 纸边发丝线 |
| `--ofs-mark` | `rgb(18 18 22 / 26%)` | `rgb(255 255 255 / 28%)` | 裁切标记与曝光单分隔线 |

深色不是把纸变黑，而是保持「光桌 < 相纸 < 卡片 < 地面（亮度）」的反向关系：相纸在任何主题下都是最亮的表面。

## Layout

页面整体采用单轨创作面板加居中画面预览结构：
- **外边距与间距**：外壳铺满无边框窗口（不再有地面留白），卡片之间统一 14px（`--ofs-gap`）：面板左侧 14px、舞台四周 14px、作品条左右与底部 14px。铺满之前那圈 18px 的浅色地面边距在桌面上会读成一道白框。
- **创作面板宽度**：单轨固定宽度——网格列 `376px`，卡片实际宽 `362px`（去掉 14px 左侧留白）。面板内部左右内边距 15px，滚动区保留 8px 滚动条槽位，内容宽度恒定，状态切换时文字不左右跳。
- **创作面板结构**：自上而下为提示词（输入框 / 英译与润色 / 可收起的润色建议）、参考图（仅当前模型支持原生参考生图时出现）、画面设置（画幅比例 → 自定义宽高折叠）、排除项（仅模型消费负向词时出现，可折叠）、高级设置（步数 / 引导强度 / 随机种子，可折叠）、页脚（生成张数 1~4 分段 → 立即生成 → 规格摘要）。生成张数是页脚常驻高频控件，不再放进高级折叠区。
- **分区标记取代分隔线**：每一组由自己的标题行起头——组名（12.5px / 600 / 墨黑）+ 一条从组名右侧起、到读数前收尾的版口发丝线（`--ofs-card-border`）+ 本组读数（11px / 等宽数字 / `ink-3`）。线属于标题，所以组与组之间不再画整幅分隔线：组内 7px、组间 14px（`--ofs-sec-gap` / `--ofs-sec-pad`，矮窗口降为 6px / 10px）。读数按组给出用户真正在意的那个数：画面设置给像素尺寸、参考图给「已用 / 上限」、排除项给已填内容（空时不显示）、高级设置给「步数 · CFG · 种子」。
- **可折叠小节 = 标题行即开关**：排除项与高级设置把整行做成开关（指针点哪都能开合），行尾右侧是一枚 20px 的箭头按钮（热区 26px，带 `aria-expanded`，键盘可达）。折叠时不渲染正文、不保留隐藏 DOM；折叠态的读数是这一节的摘要，展开后由字段自己说明，因此不再需要「卡片里再放一个带标题的折叠行」那种两层箭头。
- **开场灵感示例只出现一次**：五枚示例胶囊在舞台空白画布上；左栏不再重复同一组动作，把高度留给提示词与参数。表单里只保留「润色建议」——它改写的是当前这句提示词，和开场示例不是同一件事。
- **面板垂直预算**：面板头部 58px、页脚 122px 固定，中间内容区可滚动。就绪、等待、失败提示等常见状态在 1440×900 下内容完整落在可视区内；只有「未安装 Kaggle CLI」这类带整幅错误横幅的状态才会出现滚动——此时面板边缘常驻细滚动条，内容不被硬切在页脚上沿。折叠两节（排除项 / 高级设置）只占一行标题，所以带参考图的就绪态仍能一屏放完。
- **画廊网格**：基础为 5 列瀑布流，卡片内边距 6px，列间距 14px，图片按原生比例自适应撑高。

### 响应式断点规则
- **≤ 1400px**：画廊降为 4 列。
- **≤ 1180px**：画廊降为 3 列，品牌副标隐藏。
- **≤ 980px**：外壳保持铺满，只收紧顶栏与内部控件间距，缩略图尺寸缩小为 54px。
- **≤ 900px**：画廊降为 2 列。
- **≤ 820px**：切换为垂直单列堆叠布局：画面预览在上（42vh），创作面板在下按内容展开，两者都居中并限宽 560px；整页改为文档式纵向滚动（外壳 `.ofs-app` 自身滚动），表单不再被塞进一两百像素高的内滚动窗口，底部最近生成栏隐藏。动作坞保持自身高度，不参与剩余高度分配。
- **≤ 520px**：控件高度与字号缩减一档，画面预览收为 38vh。

## Elevation & Depth

所有阴影均为中性黑（`rgb(16 16 20)`）带正向 Y 轴偏移，严禁使用彩色阴影或零偏移发光：
- **Card (静止卡片)**：`0 1px 2px rgb(16 16 20 / 5%), 0 10px 24px -16px rgb(16 16 20 / 22%)`
- **Lift (悬浮抬升/Toast/弹出层)**：`0 2px 6px rgb(16 16 20 / 6%), 0 18px 40px -20px rgb(16 16 20 / 26%)`
- **Window (整页外壳)**：`0 1px 3px rgb(16 16 20 / 5%), 0 36px 80px -48px rgb(16 16 20 / 32%)`
- **Print (相纸)**：`0 20px 40px -24px rgb(16 16 20 / 42%), 0 4px 10px -6px rgb(16 16 20 / 18%)`；悬停加深为 `0 26px 50px -24px rgb(16 16 20 / 46%), 0 6px 14px -6px rgb(16 16 20 / 20%)`，同时上移 2px。
- **纸边不用边框画**：`.ofs-print` 用两层 0 模糊的环形阴影（`0 0 0 11px paper` + `0 0 0 12px edge`）在图片外侧描出纸边，不占布局，任何画幅都不会把纸边挤歪。
- **Focus Ring (键盘焦点)**：`0 0 0 2px var(--ofs-card-solid), 0 0 0 4px rgb(20 20 22 / 45%)`

## Motion

创作页的操作动效只有一套词汇：**换纸 (Re-sheet)** 是唯一的主角，其余只做确认与连续——**压印 (Press)**、**落定 (Notch)**、**抽屉 (Drawer)**，外加读数与面板换形两次轻反馈。等待与出图沿用原有的落定与流水线动效。时长与曲线统一取 `tokens.css` 的 `--ofs-time-*` / `--ofs-ease-*`，不在各处另写毫秒数。

### 1. 换纸（主角，420ms）
- **触发**：改画幅比例、提交自定义宽高。只发生在空态 / 新建画布的取景框上——此时台面上是一张还没曝光的空白相纸。
- **做法**：画幅比以 `@property --ofs-frame-r` 注册成 `<number>`，只过渡这个数字（`transition: --ofs-frame-r 420ms var(--ofs-ease-sheet)`）；宽度与 `aspect-ratio` 都跟着它逐帧重算，纸是被「推」到新比例的，不是跳变。不过渡 `width` 本身，所以窗口缩放时纸仍然立即跟随布局，不会被 420ms 拖住。
- **曲线**：`linear(0, 0.4 16%, 0.78 34%, 0.96 52%, 1.008 68%, 1.003 84%, 1)`，末段约 0.8% 的过冲再收回，对应裁切刀推到新画幅后的一次落定。
- **同一条时间线**：四角裁切标记跟着纸边走并重新落墨（340ms）；纸面引导文案保持常驻居中随纸边一起过渡，不做隐藏重挂载，避免换画幅时文案闪烁。
- **实测**（Edge 156，1440×900，1:1 → 16:9）：宽度 622 → 952 在前 150ms 内走完（先撞到光桌可用宽度），高度 622 → 535.5 在后 270ms 内收回，420ms 落定。
- **预算**：一次改画幅只有取景框一个元素重排，子元素全是绝对定位；不常驻、不循环。

### 2. 压印（110ms）
按下时控件向台面沉 1px 并缩到 0.985，松手回位。只给「做选择」的紧凑控件：胶囊、分段控件、画幅比例、张数、润色建议、舞台上的灵感示例。

### 3. 落定（200~260ms）
选项被选中时回位一次（`translateY(1.5px) scale(0.965)` → 原位），与换纸同一套落定曲线：画幅比例用 260ms（它和换纸是同一个动作的两端），张数、模式切换、润色建议用 200ms。

### 4. 抽屉（240ms）
折叠区（高级设置 / 排除项 / 自定义宽高 / 润色建议 / 从作品选参考图）展开时，按真实高度从 `grid-template-rows: 0fr` 长到 `1fr`，内容再落定 3px。收起时子节点真的卸载、不保留隐藏 DOM，所以只做单向：展开是抽屉拉出，收起一次到位。`overflow: hidden` 外留 5px 的负边距通道，子元素的焦点环不会被裁掉。

### 5. 两次轻反馈
- **读数**：页脚规格摘要（尺寸 · 比例 · 张数）与「画面设置」右上角读数变化时，按值重挂载并从下方 3px 浮上来（170ms），确认改的是这个数。
- **面板换形**：表单 ↔ 创作助手、创作 ↔ 画廊之间切换时，整块面板淡入落定（200ms），说明换的是同一张工作台的另一面。
- 参考图入槽时缩略图轻微弹入（200ms）；开始等待时舞台进度胶囊淡入（200ms）。

### 6. 出图与等待（沿用）
- **落定**：本次页面刚出图（60 秒内完成、且是首屏新到的那张）时播放一次，720~760ms。相纸从 `opacity .42 / translateY(10px)` 落到位，图片同时从 `blur(18px) grayscale(1) contrast(.5) brightness(1.22)` 显到清晰——对应暗房里相纸在显影液里浮出画面。`animation-fill-mode: backwards`，播完即回到基础样式，避免终帧钉住悬停抬升。
- **取景框就位**：空态/等待出图的取景框以 260ms 的 `scale .994 → 1` 淡入，说明「这一格刚放上台面」。
- **显影扫描**：进行中的批次卡里有一道 2.8s 的竖向扫描光，只表示这台机器在工作，不表示进度百分比（远端不上报步进，禁止伪造进度）。
- **流水线状态**：当前节点的 7px 圆点以 1.5 秒的节奏呼吸；已完成段的连接线走为实线，通向当前节点的那一段有一道缓慢的微流动。两者只表示「还在走」，不表示剩余时间。
- **光扫**：主按钮悬停时有一道 820ms 的斜向扫光；提交中改为 2.6s 循环，作为忙碌指示。

## Shapes

- **圆角梯度**：
  - `xl (24px)`：居中主画布外框、设置弹窗与导入弹层（窗口外壳已铺满，不再用圆角）。
  - `lg (18px)`：创作面板主卡片、画廊卡片容器。
  - `md (14px)`：主操作按钮、生图流水线、弹出层。
  - `sm (10px)`：次级按钮、参数滑块轨道。
  - `input (9px)`：参数输入框与小号分段（张数、自定义宽高）。
  - `action (8px)`：文字级动作按钮（英译 / 润色 / 从作品选择）。
  - `micro (6px)`：刻度芯片、折叠标题行的悬停底与箭头热区。
  - `pill (999px)`：属性 Chip 胶囊、分段切换轨道、顶栏 View 切换 Tab、Dock 按钮。
- **微元件圆角**：`input / action / micro` 三档只在 20~34px 高的小元件里出现，不参与卡片与外壳的圆角梯度（卡片仍走 `xl / lg / md`，不受它们影响）。
- **paper (3px)**：相纸的纸边圆角。它属于实物表面，不参与上面的 UI 圆角梯度——纸不该被做成药丸。
- **同心圆角规则**：内层元素圆角须满足 `内圆角 = 外圆角 - 间距`（例如 18px 卡片配 7px 边距时，内部图片框为 11px），避免视觉厚薄不均。相纸是放在台面上的物体，不受这条规则约束。

## Components

控件风格如同暗室印相器材：金属灰胶囊、圆角灰块与白色相纸卡，唯有主操作由墨黑实心凸显。

### 1. 按钮 (Buttons)
- **Primary CTA**：高 42px、14px 圆角；主操作渐变（`Ink Lift` → `Studio Ink`，深色主题反相为浅色渐变），文字用主题主操作文字色（浅色主题白色、深色主题墨黑）13.5px / 650；悬停上移 1px 并加深阴影，按下微缩至 0.99，禁用时保留渐变但降至 36% 透明度。禁用态的文字色也必须走主题变量，不能写死白色——深色主题的主操作是浅底墨字，写死白字会整行看不见。
- **Secondary / Ghost**：次级按钮白底 + Panel Edge 细线 + Card 阴影；Ghost 按钮为透明底搭配 `Ink Secondary` 文字，悬停切换至 `Ink Wash` 底色。
- **单实心原则**：每个独立视口最多只允许出现 1 个实心墨黑主操作按钮（立即生成或发送）。

### 2. 生图流水线 (Generation Pipeline)
等待云端与生成时，顶栏下方出现一条约 40px 高的生图流水线，用固定五节点说明当前走到哪一步：
- **骨架**：左侧固定五节点「推送内核 → Kaggle 排队 → 建立隧道 → 准备模型 → 生成」，右侧「另有 K 个排队 · 已等待 mm:ss」；会话已就绪时前四个节点折叠成一个起点「云端已就绪」，只保留「云端已就绪 → 生成」。节点措辞随算力来源切换：Colab 读作「申请实例 → 启动运行时 → 建立隧道 → 准备模型 → 生成」。
- **计时**：只在申请 GPU 阶段（推送 / 排队）从会话开始时刻算、有任务时从任务提交时刻算；连接与准备模型阶段没有可信起点（重连沿用旧会话开始时间），宁可不显示也不给虚高读数。
- **节点**：每节点只有一个 7px 圆点 + 12px 文字；已完成节点圆点转就绪绿，当前节点是墨黑圆点加一枚浅淡底（不靠颜色也能看出「现在在这一格」），待开始为空心灰点；连接线走完为实线（1px，20% 墨）；完成时最后节点显影一次（动画只播一遍），失败节点用红点，排队卡住时排队节点转琥珀并标「比平时久」。
- **表面**：与创作面板同一套中性卡片材质（`--ofs-card` + 1px `--ofs-hairline` 描边 + 14px 圆角），不使用投射阴影；等待超过 1.5 秒才淡入，高度与透明度约 200ms 过渡。
- **为什么不用进度百分比**：远端只上报当前阶段，没有采样步进与每阶段耗时，百分比只能伪造；五个离散节点能如实表达「走到哪一步」。语义色也只以 7px 圆点这种小面积出现，不侵占卡片表面。
- **相邻横幅**：排队卡与错误指引卡沿用同一套中性卡片，语义色只在左缘 2px 窄条上（等待 = 琥珀、错误 = 红），主操作使用墨黑实心胶囊。
- **响应式**：≤ 820px 只保留当前节点文字，其余节点收成圆点，队列信息并入同一行。
- **通知区**：右上角轻量通知（瞬时反馈与可恢复异常）从状态区（流水线 / 排队卡 / 横幅）的下沿展开；没有状态条时贴着顶栏下沿，有流水线时自动让开，不覆盖右侧的「已等待」读数。

### 3. 标签与分段控件 (Chips & Segmented Controls)
- **Chips**：28px 高胶囊，白色背景、Sunken 发丝描边；激活态切换为 `Ink Wash` 底色 + 墨黑文字。
- **分段控件**：3px 内边距的 Sunken Well 药丸轨道，内部切换项 26px 高；选中项使用白色背景、600 字重与 1px 微阴影。
- **单选胶囊（运行设置）**：整块胶囊就是控件——原生单选点隐去（只保留键盘焦点与读屏语义），选中态由 `Ink Wash` 底色 + 墨黑描边 + 600 字重表达，不再「胶囊里再画一个圆点」。单行选项按内容宽度排列（34px 高），不强行拉满；带限定词的选项走两行式（`is-stacked`，44px 高，名字 12px + 限定词 11px `ink-3`），四个算力来源因此能并排成一行（`is-quad`：`auto-fit minmax(110px, 1fr)`），宽度不够时自动降成两列。

### 4. 输入框 (Inputs & Search)
- **提示词区域**：外层 18px 卡片内嵌 14px 渐变浅槽（Print White → Sunken Well）；获取焦点时边框高亮并带有 3px 墨黑微光晕。
- **常规参数输入**：30px 高度、9px 圆角；单行搜索框采用 34px 高度全圆角胶囊。

### 5. 光桌与相纸 (Stage)
舞台不是又一张白卡，而是一张下凹的光桌；画面是落在桌上的一张相纸。这是全站唯一允许出现实物感的区域，控制件一律保持扁平卡片，不参与这套材质。

- **光桌**：`--ofs-mat` 底色 + 顶部径向柔光 `--ofs-mat-lit` + 内阴影 `--ofs-mat-inner` + 1px 发丝描边，24px 圆角，不使用投射阴影（凹进去的台面不该浮起来）。相纸与取景框用容器单位按「能放下的最大比例尺寸」计算并居中，出图前后尺寸一致。舞台的 `figure` 必须归零浏览器默认外边距（`margin: 0`），否则出图后相纸会比空取景框小一圈。
- **相纸**：图片外包 11px 纸边（环形阴影，不占布局）+ 1px 纸边线 + 带偏移的投影响应悬停；焦点态把外侧换成 2px 墨黑环。纸角 `paper (3px)`。
- **浮动工具**：放大 / 复制路径 / 收藏三枚玻璃胶囊贴在相纸右上角内侧 10px（相对相纸定位，不相对光桌），任何画幅下都骑在纸角上，不会悬在纸边上。
- **空态与等待出图 = 一张还没曝光的空白相纸**：同一材质、同一位置，比例跟随当前画幅（或本次任务的宽高），四角配 15px 裁切标记。切换「画面设置」里的比例时，台面上的纸跟着换形状——这是选择画幅时最直接的反馈。
- **曝光单**：空态纸面下沿留白里一行「稳定出图约 6.2秒」，取自当前预设的 `steadySeconds`，两侧用 `--ofs-mark` 发丝线收住；让用户在点生成前就知道这一张要等多久。读不到预设时不显示，绝不编数字。它固定在纸面下沿，不参与居中内容的排版。
- **进行中**：还没有图、取景框里也还没有引导文案时，进度胶囊落在空取景框正中；取景框里有标题与说明时（显式新建画布），胶囊排进文案流（标题 → 说明 → 进度），不浮层压字；已有图时，胶囊浮在相纸下方。
- **题注**：图下一行提示词（12px / ink-2）+ 一行标签式参数（11px / +0.07em 字距 / tabular-nums：尺寸 · 耗时 · 种子）。参数行按印相室标签的写法处理，不抢画面。

### 6. 最近生成栏 (Filmstrip)
- **批次卡**：62px 缩略图（小屏 54px）+ 下方模型名与张数，选中项加墨黑描边环，悬停上浮 2px。
- **进行中卡**：一格 46px 虚线取景框（内含一道竖向显影扫描光）+ 阶段文案 + 已等待时间。只描述真实阶段与真实耗时，不显示假进度。
- **排队卡**：队列串行执行，但可能有多个待执行任务，每个任务各占一张卡，按执行顺序从左到右排在批次卡之前。排队中的任务还没开始出图，取景框里不出现显影光，取而代之的是它在队列里的位次（14px 数字），旁边是阶段文案与已排队时长；悬停显示该任务的完整提示词。位次从整条队列算起，「进行中」占第 1 位。
- **空态**：三格虚线空位 + 一句说明；云端未启动时给「唤醒」链接。

### 7. 模型选择卡 (Model Card Picker)
顶栏右侧的模型入口（自绘窗口按钮在其右），替代原生 `<select>`：
- **触发胶囊**：与云端状态胶囊同高 34px，内容依次为调优图标、家族徽标（SDXL / FLUX，文字徽标而非彩色 Logo）、模型短名、实测稳态耗时（如 `~6.2s`）、折叠箭头；`≤1120px` 收起耗时段。
- **弹层**：宽 `min(380px, 100vw - 32px)`、最大高 420px，与云端状态弹层同构（16px 圆角、`--ofs-shadow-lift`、下移 8px、`z-index 40`）；头部写「出图模型 / 实测稳态耗时」，底部声明「海报为概念示意，非出图样例」。
- **选项卡片**：56×56 海报（唯一允许的彩色区域）+ 家族标签 + 模型短名 + 「默认」标记 + 一行定位描述 + 参数规格 + 右对齐实测耗时；选中项浅墨底、微环与对勾。海报图片本身是 Pexels/Unsplash 真实照片，构建期以 data URL 内联，运行时零外部请求。

### 8. 作品画廊 (Gallery)
5 列自然高度瀑布流卡片墙，展示图片预览、参数题注与模型/种子胶囊；悬停卡片上浮 2px。
悬停操作条依次为「带回参数 / 生成变体 / 以此图重绘 / 查看大图 / 删除」：删除是唯一的破坏性动作，常态淡红描边，首次点击只把按钮切成实心红的「确认删除」并收起其余动作，再点一次才落盘删除；移出卡片或点「取消」即收起确认态。

### 9. 参考图槽 (Reference Slot)
左栏「参考图」小节的槽位是一行 **96px 方格**：已挂的缩略图与两个入口（`选择图片` / `从作品选择`）同尺寸、同圆角（`sm 10px`）、间距 8px，所以「挂了几张、还能加、从哪加」在一条线上说完。标题带后缀注记 **（可选）**（11px / 500 / `ink-3`，紧贴组名）——「这一项可以不管」是字段性质，常驻可见，不靠 hover 才说得清。
- **空槽**：两个入口平分整行（各 ≤168px），虚线 18% 墨——比普通描边重一档，否则读成占位而不是能点的地方。
- **有图**：入口收回 96px，与缩略图对齐成槽位带；未满时入口常驻，满额后入口消失、下方补一句「参考图已满 N 张」（`ink-2`）。
- **缩略图**：铺满方格、`object-fit: cover`；悬停压深 6%（`brightness .94`）并提亮右上角 22px 移除钮（悬停转红），热区向外扩到 44px。文件名不进版面，放在 `title` 与 `alt` 里。
- **拖入**：整节仍是 drop target，悬停时只给槽位带一圈 30% 墨虚线 + 浅底，入口格的虚线同时收成实线，避免两层虚线相叠。
- 入口与缩略图都吃「压印」的按下手感；新入槽的缩略图播一次 200ms 的弹入。

### 10. 窗口标题栏与窗口按钮 (Window Chrome)
主窗口是无边框窗口（Windows / Linux `frame:false`），系统标题栏不再存在，**顶栏本身就是标题栏**：整条 `.ofs-topbar` 是拖动区，空白处按住即可移动窗口，双击最大化；所有按钮、输入框、Tab 轨道、胶囊与弹层都显式 `no-drag`，点控件不会误拖窗口。
- **按钮组**：顶栏最右三枚 30×30、圆角 `9px` 的图标按钮（最小化 / 最大化 / 关闭），图标沿用同一套 1.6px 线稿；与模型胶囊之间以 1px `hairline` 竖线分隔并留 10px 内距，把「业务控件」与「窗口控件」分成两层。
- **状态**：最大化后中间按钮换成「还原」图标，标题与 `aria-label` 同步；状态由主进程在 `maximize / unmaximize / enter-full-screen / focus` 等事件上广播，双击拖动条最大化也能收到。
- **悬停**：最小化与最大化用 `accent-soft` 中性墨底，关闭是唯一的破坏性动作，悬停切到 `error-soft` 底 + `error` 图标；不加红点常驻，避免顶栏出现第二处语义色。
- **不伪造系统能力**：关闭调用 `BrowserWindow.close()`，与托盘菜单、`Alt+F4` 同一条路径，云端会话 / 任务活跃时仍会被拦截并隐藏到托盘（防烧额度）；按钮不提供「强制退出」。
- **外壳铺满窗口**：`.ofs-root` 不留地面边距，`.ofs-app` 不画外框与投影——无边框后若还留 18px 浅色边距，桌面上会读成一道白框。卡片之间仍是 14px，由面板 / 舞台 / 作品条自己的 margin 提供；窗口四角交给 Windows 11 的系统圆角裁切。
- **macOS**：保留系统交通灯（`titleBarStyle: hiddenInset`），渲染层不重复画按钮，顶栏左侧让出 84px；浏览器直连 / 预览态没有窗口能力，按钮组不渲染。

### 11. 导入图锁定态 (Import Focus Lock)
舞台焦点落在裸本地导入图（或它直接放大的产物）上时，左栏表单 / 助手顶部换成一条 10px 圆角的强调浅底引导条：12px 图标 + 11px 标题「本地导入图」与一枚 22px 高的「新建创作」胶囊按钮同行，下方只留一行 11px 说明（表单：重绘 / 扩图 / 放大请用舞台底部工具；助手：已有对话保留）——两行高，不再复述面板里已有的信息。引导条之外的编辑区整体降到 55% 不透明度并降饱和（`inert` 阻断焦点与点击），字段值与对话原样保留；不画全屏遮罩、不弹窗，解锁后立即恢复原样。助手坞里只有输入区被降权，「停止生成」留在可用区，避免切到导入图后无法中断在途请求。

### 12. 算力状态弹层 (Compute Popover)
顶栏算力胶囊展开的面板只回答四个问题，一段一条发丝线收口：状态 → 额度 → 环境检查 → 动作。弹层本身就是那张卡，段内只用排版分层，不再往里塞第二层卡片。

- **状态**：语义圆点 + 来源图标 + 「来源 · 状态」，下面一行读数（设备 · 实测秒/张 · 闲置关机阈值，点分隔、超长省略，全文在 `title` 里）；已有空闲倒计时时，阈值让位给倒计时与 5px 进度条。只有非就绪态才补一句阶段说明（就绪时说「可以生成」属于复述）。独立阶段徽章取消：状态标签本身已按阶段分档。
- **额度**：唯一的凹槽面。Kaggle 有分母，用 56px 环形仪表（环上讲剩余，文字讲「已用 x / y 小时」）；Colab 的 CCU 是余额不是比例，改用 56px 读数位（19px 数字 + 9.5px 单位，比环形仪表中心的 12.5px 略大，因为它独自承担这一格的主读数），余额 <15 / <3 时数字转琥珀 / 红——不画一个会被误读成「剩余百分比」的圆环。配额读不到时整段换成回退说明（最近一次成功检查 + 本次会话时长 + 账户设置链接），不同时摆一个空环。
- **环境检查**：三项全过收成一行「环境检查通过」；只有没过的项各占一行，写成 `标签 · 读数`，手机号绑定提醒跟着账号行出现。「检查环境」是这三行的三级动作（透明底 + 图标），贴在它读的读数右侧，不再单独占一行菜单项。
- **动作**：只给当下能做的那个（唤醒 / 连接，或关闭云端 / 断开），不摆一个永远点不动的另一半；其后两行是运行日志与设置。
- **其余来源复用同一骨架**：商业 API 把额度位换成计费摘要、检查行换成服务商；私有 Worker 换成设备名与「连接地址 / 访问令牌」，不另起一套版式。

### 13. 运行设置（云端算力）(Settings · Compute)
- **一层容器**：每个算力来源只在选中时展开自己那块 `.ofs-settings-subpanel`，里面直接是字段与选项；授权状态用区块标题行右端的 22px 状态胶囊（`.ofs-settings-block-badge`）表达，不再套一张带投影的白卡。
- **一套区块头**：Colab / 私有 Worker / 商业 API 共用 `.ofs-settings-block-head`——裸图标（不再装进描边方块）+ 来源名 + 一行状态 / 说明，标题名一律取 `providerLabelOf`（与顶栏胶囊、状态弹层同名），不再出现「Colab Pro（需授权）」「商业生图 API」这类只属于选择阶段的变体。
- **三步授权进度**只在还没授权时出现：已授权时三枚对勾只是复述结论，收掉后这一块剩「标题 / 状态 / 说明 / 重新授权」四行。
- **说明不重复**：同一件事只说一次——「凭据保存在本机」由授权块正文承担，区块底部不再补一句「仅保存在本机」；计费摘要给了单价就不再补一句同义解释。
- **字段行只有一种排版**：标签在左、读数紧随、动作贴行尾（`接口地址 https://… 修改`）；折叠态展示读数本身，不拿「修改接口地址」这种动作当标签。
- **商业 API 区块的节流**：服务商名不在 Key 状态里重复（选中项的「已配」标记收起，状态由 Key 行承担）；「多个用逗号分隔」只在占位符里说一次；「模型去哪选」只在没有模型字段时提示一行；能力边界压成一句（`阶段 A 仅支持文生图；重绘、扩图等请切回…`）。

### 14. 视频产物与抽帧 (Video Stage & Frame Capture)
视频沿用相纸容器，但不再是「可点开的图」：它是一个带原生控制条的播放器，且不参与图片那一套派生语义。

- **播放器即画面**：`.ofs-print--video` 里放原生 `<video controls autoPlay loop playsInline preload="metadata">`，去掉悬停抬升、显影动画与「点开大图」暗示；放大层同样换 `<video>`，不再挂「以此图重绘」。
- **动作坞整体让位**：涂抹重绘 / 扩图 / 高清放大都建立在静态像素上，对视频没有意义，视频作品直接不渲染动作坞，避免摆一排点不动的按钮。
- **抽帧条单列**：相纸下方一行 30px 胶囊 `取首帧 / 取尾帧`（`.ofs-video-capture`，裸 `film` 图标 + 12px 文字，居中、间距 8px）。它不属于动作坞——抽帧是「把视频还原成图片」的输入准备，产物会落成一张普通作品，之后才进动作坞与参考图槽。
- **读数讲片长**：题注第三格显示 `5 秒`（片长），生成耗时不再顶替片长；胶片条与聊天气泡同一口径，缺片长时只显示「1 条」而不是回落成等待耗时。
- **缩略图只取首帧**：胶片条 / 画廊 / 聊天网格用 `<video muted preload="metadata" src="...#t=0.1">` 当静帧，不自动播放、不发声，避免一屏多个视频同时跑。
- **左栏与顶栏模式协同**：顶栏提供 `[生图 | 视频]` 创作模式切换（模型卡仍保留「本地 / 各服务商」主 Tab 与次级模态过滤芯片，点选跨模态模型自动双向切换模式）。视频模式下左栏「画面设置」切换为「视频画幅」（直接读模型 `ratios` 含 `21:9`，隐藏自定义像素宽高，挂载首帧时自动锁定并提示跟随首帧）；「首尾帧」槽位显式标注 `首帧 / 尾帧` 角标并提供「对调首尾」；时长滑杆（5–15 秒）与分辨率分段（`480p` / `768p`）直接展开成一级「视频参数」，不再埋进折叠高级区；页脚隐藏张数、改「画幅/跟随首帧 · 时长 · 分辨率 · 1 条」；空白/等待态舞台使用暗色导演取景框（`.ofs-frame--video`）与动态运镜灵感示例。

### 15. 作品改写与分叉取景态 (Draft Fork & Reference Fly-in)
查看历史作品并改动左栏参数时，不再依赖顶部「基于此图：…」「已修改… · 尚未生成」状态条解释内部状态，而用空间关系与控件分工直接传达因果：
- **未改动零提示**：点选作品后舞台、胶片条与表单已经各自呈现内容，顶部不再多占一行说明来源。
- **顶/底分工明确**：基于当前作品改过参数后，顶部「提示词」标题行右端出现零占位 `重置参数`（`.ofs-reset-params`），页脚主按钮从 `立即生成` 切为 `生成新图` / `生成新视频`——一眼看清“退路在右上、点主按钮会出新图且不改原图”。
- **非文本区就地亮点**：只有「参考图 / 画面设置 / 排除项 / 高级参数 / 张数」在相对原图变化时亮出与胶片条草稿同色系的 6px `.ofs-fieldset-dot` 与微弱暖色版口线；「提示词」标题本身不亮圆点不变色，避免打字时在视线正上方制造噪音。
- **光桌分叉取景态（`.is-draft-fork`）**：修改期间右侧舞台原图缩退微倾（`scale(0.84) rotate(-1.2deg)`，悬停回浮便于细节对照），前景叠出跟随 `--ofs-fork-r` 实时滑移的虚线取景框 `.ofs-fork-frame` 与 `将生成新图 · {spec}` 徽标；点 `重置参数` 后通过 `usePresence` 播 220ms 退场同时原图弹簧归位。
- **参考图抛物线飞入**：在舞台通过「设为参考图」或「切换支持参考的模型」把当前作品送入参考槽时，由 `ReferenceFlyOverlay` 以 580ms WAAPI 采样抛物线（上抛 → 下落 → 填充放大回弹）飞入左侧 `[data-ref-path]` 槽位；普通改词/改参不静默塞入参考图，避免污染纯文生图或锁死视频首帧画幅。

### 16. 资产工坊 (Asset Workshop)
工坊是独立整页视图（顶栏 `创作 | 工坊 | 作品库` 的中间段），处理「出图之后的确定性加工」：像素对齐、序列帧切片、无缝平铺、SVG 矢量、抹除背景与 PBR 材质拆解。它不进主舞台，避免专业参数污染日常创作。

- **两段式页面**：上半是工具条（`.ofs-workshop-head`，六枚工具胶囊 + `返回创作`），下半是 `.ofs-workshop-body`——左栏「最近作品 + 本地上传 + 工具参数」，右侧棋盘格画布与通道条；底栏 `.ofs-workshop-foot` 只放 `保存到作品库` / `导出 ZIP` 与状态读数。
- **预览与应用分离**：像素对齐、切片、平铺、矢量化都是「调参即预览，点应用才产出结果」。预览永不写盘，避免每拖一次滑杆就在作品库留一张废图；`应用` 之后底栏状态读到 `结果 512×512 · 可保存`，此时保存才落盘成一条新作品。
- **棋盘格是底层语义**：画布默认铺透明棋盘格（`.ofs-workshop-checker`），抹除背景 / PBR 的透明与法线通道都在这块底上检查白边与硬边；图片源与结果共用同一块 canvas，通道切换只是换绘制内容，不做二次解码。
- **工具语义按本机 / GPU 分色**：像素对齐、序列帧、平铺、SVG 四类是本机确定性算子（渲染进程 canvas + Node WASM，0 GPU），点应用即出结果；抹除背景与 PBR 是 GPU 后处理，点击只提交任务，进度复用顶部流水线与任务卡，结果由宿主落盘后成为带通道的作品。
- **结果是一张卡，不是四张**：PBR 四通道、序列帧 atlas、SVG 副本都挂在同一作品下（`.ofs-workshop-channels` 通道条切换预览），画廊 / 胶片条只占一张卡并带通道角标；复合资产包与版本树继续兼容（工坊产物挂在来源作品的 `rootImage` 树下）。
- **动作坞只留两个入口**：主创作台 Stage 底部新增第三组 `asset`——`抹除背景`（直接对当前作品提交 GPU 算子）与 `进工坊 ↗`（带当前作品进入工坊页）。高频刚需在舞台上一步直达，细分加工进工坊慢慢调。

## Do's and Don'ts

### Do
- **Do** 坚持以画面为主角，让所有控件与参数面板退守至边缘灰阶卡片中。
- **Do** 把相纸与光桌当作真的物体：纸边、裁切标记、题注标签三者一起说明「这是一张已经落定的图」。
- **Do** 仅使用 1.6px 圆角描边的轻量手写 SVG 图标，保持全站视觉语言完全同构。
- **Do** 保持中性黑阴影（`rgb(16 16 20)`）并配合正向 Y 轴位移，呈现真实物理投射感。
- **Do** 保证所有交互按键具备可见的键盘焦点环（Focus Ring），支持动效减退。
- **Do** 等待过程只讲真话：阶段、已等待时长、预设的实测出图速度，都可以显示；进度百分比在远端不上报步进前一律不显示。
- **Do** 让每一组由自己的标题行起头（组名 + 版口线 + 读数）：组内紧、组间松，边界靠这条属于标题的线说明，不靠整幅分隔线。

### Don't
- **Don't** 使用大面积彩色渐变、炫光或饱和彩色阴影。
- **Don't** 引入外部位图文件、字体包或 Emoji 符号作为系统图标；唯一例外是模型选择卡的 8 张 56×56 海报（112/96px WebP 构建期内联，base64 总量 ≤20KB）。
- **Don't** 在单屏视口内放置两个或以上的实心深色按钮。
- **Don't** 把光桌/相纸这套实物感扩散到其他界面：控制件一律扁平卡片，否则整页会变成一堆拟物盒子。
- **Don't** 破坏同心圆角规则导致内层切角外露或边距不协调（相纸等实物表面按 `paper (3px)` 处理）。
- **Don't** 把可折叠小节的标题做成纯标签：标题行就是开关，折叠态的读数是里面装了什么的唯一说明；也不要「卡片里再放一个带标题的折叠行」，那会出现两层箭头和一句重复的标签。
